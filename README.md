# 💻 Windows 98 Style Portfolio

Este é o meu portfólio pessoal, desenvolvido com uma interface nostálgica inspirada no Windows 98. O objetivo deste projeto foi demonstrar o domínio de tecnologias web fundamentais e a capacidade de criar interfaces ricas e interativas do zero.

## 🚀 Acesse o Projeto
O portfólio está disponível em: [antoniolelis.github.io](https://antoniolelis.github.io/)

## 🛠️ Tecnologias Utilizadas
Para garantir performance e demonstrar conhecimento de base, o projeto foi construído **sem frameworks**:
* **HTML5:** Estruturação semântica de componentes e janelas.
* **CSS3:** Estilização retro, sistemas de camadas (z-index) e responsividade.
* **Vanilla JavaScript:** Lógica de manipulação do DOM, gerenciamento de estados das janelas (abrir/fechar/arrastar) e simulador de terminal.

## ⚙️ Funcionalidades Principais
* **Sistema de Janelas:** Implementação manual de lógica para arrastar e organizar janelas na tela.
* **Interface Responsiva:** Adaptação da experiência desktop clássica para dispositivos móveis.
* **Interatividade Retro:** Menu Iniciar funcional, relógio em tempo real e simulador de aplicativos.

## 🧠 O que este projeto prova?
Diferente do uso de bibliotecas de UI modernas, este projeto exigiu:
1. **Domino de Event Listeners:** Gerenciamento de eventos de mouse e toque.
2. **Lógica de Posicionamento:** Cálculo de coordenadas em tempo real para o movimento das janelas.
3. **Clean Code:** Organização de um projeto complexo mantendo o código puro e legível.
